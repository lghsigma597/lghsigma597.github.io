# lghsigma597.github.io

Resume site of Gihyeon Lee (이기현), in English and Korean. One static page with no build step.

## Edit

- All content is in `index.html`.
- Text that changes with the language comes in pairs: one element with `data-l="en"` and one with `data-l="ko"`.
- Placeholder text has `class="ph"`. Replace the text and remove the class.

## Preview

```bash
python3 -m http.server 8000
```

Open <http://localhost:8000>.
